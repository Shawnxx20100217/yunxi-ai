# Parallel Desk 0.4.27 · 云隙 AI

macOS 悬浮窗工具，把 ChatGPT 等 AI 网页、截图和文字识别放到手边。

A macOS floating workspace for web AI chats, screenshots and text recognition.

**macOS 13+ · Apple 芯片与 Intel / Apple silicon & Intel · 公开下载需要激活 / Public downloads require activation**

[下载最新版 · Download the latest version](https://github.com/Shawnxx20100217/yunxi-ai/releases/latest)

## 主要功能 · Features

- **AI 悬浮窗 / Floating AI workspace**：在 ChatGPT、Gemini、Grok、DeepSeek 之间切换。<br>Switch between ChatGPT, Gemini, Grok and DeepSeek.
- **截图上传 / Screenshot attachments**：框选或一键全屏截图，直接添加到网页聊天框；按住 Option 多次按 S 可把同一道题的多张图一起发送。<br>Capture a region or the full screen, or batch several parts of one question with Option+S.
- **答案字母提示 / Answer Letter Hint**：可选功能。截图发送并收到确定的单选题答案后，在鼠标旁显示清晰的 A–G 标签，5 秒后自动消失；聊天窗口保持隐藏。<br>Optional clear A–G badge beside the pointer after a confirmed multiple-choice answer; it disappears after five seconds while the chat window stays hidden.
- **文字识别 / Text recognition**：截图识字、获取选中文字，直接填入网页。<br>Extract text from screenshots or selected text and insert it into the web chat.
- **显示与归档 / Window and archive**：透明度、网页缩放、置顶、全屏应用上方显示；原图按日期保存到桌面「Parallel Desk 截图」。<br>Opacity, page zoom, always-on-top and full-screen overlay; dated originals are saved to Desktop/Parallel Desk 截图.

题目通过截图提交，支持图表，不依赖题目网页结构。无法确认答案时不显示字母。本版本不包含滚动长截图。

Questions are submitted as screenshots, including charts, without matching the question page structure. No letter appears when the answer is uncertain. Scrolling long screenshots are not included.

**LockDown Browser：作者报告已实测可用；具体版本与使用环境待补充，不保证所有配置兼容。**

**LockDown Browser: the author reports successful testing; compatibility is not guaranteed across every version or environment.**

## 安装使用 · Getting started

1. 下载并解压，打开「安装或更新 Parallel Desk」，点击安装或更新。<br>Download and extract the archive, open “Install or Update Parallel Desk”, then choose Install or Update.
2. 客户版首次打开时复制设备识别码，联系管理员获取激活码；支持永久及限时授权。<br>On first launch of the customer edition, copy the device ID and contact the administrator for a permanent or time-limited activation code.
3. 在 Parallel Desk 内登录需要使用的 AI 平台；如需答案标签，在设置开启「答案字母提示」。<br>Sign in to the AI platform inside Parallel Desk; enable Answer Letter Hint in Settings if needed.

屏幕录制权限和辅助功能权限只给主程序 Parallel Desk，不需要给安装器。AI 平台账号和可用网络需自行准备。

Grant Screen Recording and Accessibility to the main Parallel Desk app, not the installer. Your AI account and network connection are your responsibility.

## 常用快捷键 · Keyboard shortcuts

| 快捷键 / Shortcut | 功能 / Action |
| --- | --- |
| Option + Command | 显示／隐藏窗口 / Show or hide |
| Option + S | 全屏截图；按住 Option 多次按 S 后一起上传 / Full-screen capture; hold Option and press S repeatedly to batch-send |
| Option + I | 框选截图 / Capture a region |
| Option + T | 截图识字 / OCR screenshot |
| Option + D | 获取选中文字 / Capture selected text |
| Option + B | 切换不透明与上次透明度 / Toggle full opacity and previous opacity |
| Option + E | 退出程序 / Quit |
