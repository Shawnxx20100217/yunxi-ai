# 云隙 AI

一款 macOS 悬浮窗工具，把 AI 网页、截图和文字识别放到手边。

**macOS 13 及以上 · 支持 Apple 芯片和 Intel · 使用前需要激活**

[下载最新版](https://github.com/Shawnxx20100217/yunxi-ai/releases/latest)

## 主要功能

- 在悬浮窗中切换 ChatGPT、Gemini、Grok、DeepSeek。
- 框选或一键全屏截图，直接添加到网页聊天框。
- 截图识字、获取选中文字，直接填入网页。
- 调整窗口透明度，支持置顶、全屏应用上方显示和右上角唤出。
- 截图按日期和时间自动保存到桌面的「云隙 AI 截图」文件夹。

## 安装使用

1. 下载并解压安装包，打开「安装或更新云隙 AI」，点击「安装并打开」。
2. 首次打开时复制设备识别码，联系管理员获取激活码。
3. 完成激活，登录需要使用的 AI 平台即可使用。

截图需要「屏幕录制」权限，读取选中文字可能需要「辅助功能」权限；请把权限授予主程序「云隙 AI」。各 AI 平台的账号和订阅需自行准备。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| Option + Command | 显示／隐藏窗口 |
| Option + T | 截图识字 |
| Option + S | 一键全屏截图 |
| Option + I | 框选截图 |
| Option + D | 获取选中文字 |
| Option + B | 切换不透明／上次透明度 |
| Option + E | 退出程序 |
