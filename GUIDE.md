## macOS 中文

### 第一次使用

1. 从[下载页](README.md)获取 Mac 安装包，解压并打开「安装或更新Parallel Desk」，点击「安装并打开」。已安装过的用户选择「更新并打开」。以后从应用程序文件夹打开 **Parallel Desk** 即可。
2. 在「联系管理员」页复制设备识别码，发给管理员。收到激活码后，完整粘贴并点击「激活并打开」。菜单栏的「授权／续期」可以查看截止时间或输入续期码。
3. 在小窗口左上角选一个 AI 平台，用自己的账号登录并打开对话。软件的设备授权与 AI 平台订阅分别办理。
4. 第一次截图时，在「系统设置 → 隐私与安全性」里给安装好的 **Parallel Desk** 开启屏幕录制权限。使用鼠标侧键或读取其他应用中已选的文字，还需要辅助功能权限。若 macOS 提示重新打开，请按提示操作。

### 截一张，或把几张放进同一条消息

- **一张全屏图**　将鼠标移到要截取的显示器，按 **⌥ S**，然后松开 **⌥**。只截一部分请用 **⌥ I** 框选。
- **同一条消息放多张图**　保持按住 **⌥**，每到一处要截的内容就按一次 **S**，全部截好后松开 **⌥**。每组最多 10 张。
- **鼠标侧键**　在设置中开启「鼠标侧键全屏截图」，录入按钮，关闭设置窗口后使用。「按住滚动，松开发送」适合连续阅读同一页，按住侧键截取第一张，滚动后稍停约半秒补拍，松开后整组上传。「截图键＋发送键」使用两个不同的侧键，一个逐张暂存，一个提交整组。

**ChatGPT 和豆包**默认在截图上传完成后自动发送。如果想先检查图片或补充问题，在设置里关闭「ChatGPT／豆包截图上传完成后自动发送」。使用 **Gemini、Grok、DeepSeek** 时，请在网页里确认附件后手动发送。普通截图上传或回复生成期间，隐藏与重新打开窗口都可以继续使用。

### 窗口、回复与截图存档

点击菜单栏图标可打开功能菜单。拖动窗口边缘可调整大小。工具栏可切换置顶，设置中可调整网页缩放。喜欢用鼠标开关窗口时，在设置中开启「鼠标移入屏幕右上角立即显示／隐藏窗口」。进入一次切换一次，离开后再移入即可再次切换。

ChatGPT 和豆包支持可选的答案字母提示和简短答案自动复制，两项在每次启动时默认关闭。自动复制会用本次简短回答替换剪贴板内容。要回到小窗口查看完整对话，请先关闭已开启的这两项功能。

截图原图按日期和时间保存在桌面的 **Parallel Desk 截图** 文件夹，可从菜单栏点「打开截图文件夹」。全屏上传使用轻量副本。提交到第三方平台的图片和文字会交给该平台处理。请选择有权分享的内容，遵守学习、作业及考试的使用规则。

### 遇到问题

- **图片已保存，聊天框里没有消息**　打开小窗口查看底部提示，检查当前平台是否登录、附件是否上传完、输入框是否有未发送的草稿。先检查这张图是否已在聊天框里，再决定是否手动发送。
- **快捷键或侧键无反应**　点击菜单栏图标试用对应功能。截图失败时核对屏幕录制权限。如果只有侧键失败，关闭设置窗口，确认已录入侧键、已授权辅助功能，鼠标驱动里的按钮类型是标准侧键。
- **启动时显示「需要更新 Parallel Desk」**　点「打开下载页」，下载新版 Mac 安装包，解压并选择「更新并打开」。同一台 Mac 的正常升级会保留激活信息。

## macOS English

### First launch

1. Get the Mac package from [Downloads](README.md), unzip it and open the installer. Choose **安装并打开** (Install and Open) or **更新并打开** (Update and Open). For everyday use, open **Parallel Desk** from your Applications folder.
2. Copy the device code from the activation screen and send it to the administrator. Paste the activation code you receive and select **激活并打开** (Activate and Open). The menu bar item **授权／续期** shows your expiry date and accepts renewal codes.
3. Choose an AI provider at the top left, sign in with your own account and open a conversation. AI provider subscriptions are separate from the Parallel Desk device licence.
4. When macOS asks, grant the installed **Parallel Desk** app screen recording access in **System Settings → Privacy & Security**. Mouse side buttons and reading text selected in another app also need Accessibility access. Reopen Parallel Desk if macOS asks you to.

### Capture and send

- **One screenshot** — Move the pointer to the display you want, press **⌥ S**, then release **⌥**. Press **⌥ I** to select an area instead.
- **Several screenshots in one message** — Hold **⌥** and press **S** at each point you want to capture. Release **⌥** to upload the group. A group can contain up to 10 images.
- **Mouse side buttons** — Enable side-button capture in Settings, record your button and close Settings. In hold-and-scroll mode, hold the button for the first image, scroll and pause for about half a second for each additional image, then release to upload the group. In two-button mode, one button collects individual screenshots and the other uploads the group.

**ChatGPT and Doubao** send automatically once the screenshots finish uploading by default. Turn off screenshot auto-send in Settings to review the attachments or add a question first. With **Gemini, Grok or DeepSeek**, check the attachments and send from the provider’s chat. You can hide or reopen the chat window during an ordinary screenshot upload or while the reply is being written.

### Window, replies and saved images

Use the menu bar icon to open the app menu. Drag a window edge to resize it, use the toolbar pin to keep it on top, or change page zoom in Settings. To toggle the window using the mouse, enable the top-right hot corner in Settings. Move into the corner once to toggle, then leave and re-enter to toggle again.

ChatGPT and Doubao offer an optional answer badge and short-answer copying. Both start off at each launch. Automatic copying replaces the current clipboard contents with the short reply. Turn off any active answer badge and auto-copy options to return to the chat window for the full conversation.

Originals are saved by date and time in **Parallel Desk 截图** on the Desktop. Choose **打开截图文件夹** from the menu bar to open the folder. Full-screen uploads use a smaller copy. Any images and text you submit are processed by the selected provider. Share only material you have permission to share and follow the rules for your coursework and exams.

### Troubleshooting

- **The image was saved but no message appeared** — Open the chat window, read the status at the bottom and check your sign-in, upload progress and any existing draft. Check whether the image is already attached before sending manually.
- **A shortcut or side button does nothing** — Try the same action from the menu bar. For screenshot problems, check screen recording permission. For side buttons, close Settings, check the recording and Accessibility permission, and make sure the mouse driver sends standard side-button events.
- **An update is required at launch** — Choose **打开下载页** to open the release page, download and unzip the new Mac package, then choose **更新并打开**. Updating on the same Mac keeps your activation.

## Shortcuts

⌥ Option · ⌘ Command · ⇧ Shift

| 快捷键 / Keys | 功能 | Action |
| --- | --- | --- |
| ⌥ ⌘ | 显示或隐藏聊天窗口 | Show or hide the chat window |
| ⌥ S | 截取鼠标所在的显示器，松开 ⌥ 上传 | Capture the display under the pointer and release ⌥ to upload |
| ⌥ I | 框选截图 | Capture a selected area |
| ⌥ T | 框选文字，在本机识别后填入聊天框 | Recognize text in a selected area and insert it into chat |
| ⌥ D | 将其他应用中选好的文字填入聊天框 | Insert text selected in another app |
| ⌥ ⇧ S / ⌥ Return | 暂存一张全屏图 / 提交已暂存的一组 | Queue a full-screen image / submit the queued group |
| ⌥ P / ⌥ A | 切换答案提示 / 回看上次答案约 5 秒 | Toggle the answer badge / recall the last answer for about five seconds |
| ⌥ B | 切换不透明和上次使用的透明度 | Toggle between opaque and the last transparency setting |
| ⌥ E | 退出 Parallel Desk | Quit Parallel Desk |

## Windows

1. **安装 / Install**　Windows 10 或 11 的 64 位电脑可使用 EXE 安装器。如果选择 ZIP，请先完整解压，再打开文件夹里的 `Parallel Desk.exe`。  
   On Windows 10 or 11 x64, use the EXE installer. If you choose the ZIP, extract the entire folder, then run `Parallel Desk.exe` inside it.
2. **激活 / Activate**　复制这台 Windows 电脑显示的设备码，向管理员申请对应的激活码。更换电脑或从 Mac 转到 Windows 时，需要为新设备申请。  
   Copy the device code shown on this Windows PC and request its activation code from the administrator. Request a new code when moving to a different computer or switching from Mac to Windows.
3. **开始使用 / Start a chat**　在应用中选 ChatGPT、Gemini、Grok 或 DeepSeek，登录自己的账号并打开对话。  
   Choose ChatGPT, Gemini, Grok or DeepSeek, sign in to your account and open a chat.

| Windows 快捷键 / Keys | 功能 | Action |
| --- | --- | --- |
| Ctrl + F | 显示或隐藏窗口 | Show or hide the window |
| Ctrl + S | 截图 | Capture a screenshot |
| Ctrl + B | 切换透明度 | Toggle transparency |
| Ctrl + Shift + R | 刷新当前平台 | Reload the current provider |
